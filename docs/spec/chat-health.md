# Здоровье чатов

Проверка прав бота в Telegram-чатах, health-ключи, тревоги и discovery
новых чатов. Читаемое зеркало спеки `chat-health`.

## Startup health

При старте бот проверяет все четыре настроенных чата:

- `boosty_group`
- `tribute_channel`
- `club_chat`
- `club_channel`

Для каждого чата выполняются `getChat` и `getChatMember(chat, botID)`.
Бот должен быть администратором с нужными правами. Результат пишется в
стабильные ключи `meta.health.*`: `ok` или `fail:<reason>`.

Если проверка не проходит, бот логирует проблему, создаёт
`admin_alert` и отправляет DM владельцу, но не падает. Severity зависит
от ресурса: `critical` для клубных чата и канала, `error` для источников.
При успешном startup health stale-alert с тем же title закрывается.
Повторные рестарты в деградированном состоянии не плодят одинаковые
открытые alerts.

## DM state через `my_chat_member`

`my_chat_member` из лички обновляет `users.dm_state`:

- пользователь заблокировал бота → `blocked`;
- пользователь разблокировал бота → `open`.

Если пользователь заблокировал бота, не отправляя `/start`, обработчик
сначала создаёт минимальную строку `users`, а потом выставляет
`dm_state`. Обновление DM-state узкое и не затирает admin-owned поля
пользователя.

## Права в известных чатах

`my_chat_member` из одного из четырёх настроенных чатов обновляет
соответствующий `meta.health.*`.

При потере прав бот пишет `audit_log(bot_rights_lost)` и открывает
`admin_alert`. При восстановлении прав пишет
`audit_log(bot_rights_restored)` и закрывает открытую тревогу для этого
чата. Это делает live-события и startup health симметричными: проблему
можно обнаружить и закрыть как при работе бота, так и после рестарта.

## Discovery незнакомых чатов

Когда бота добавляют в незнакомый чат или канал, бот логирует полную
операторскую информацию о чате: `chat.id`, тип, title, username,
forum/direct-messages flags и actor, который сделал изменение. Владельцу
также уходит DM с ID и типом, чтобы эти значения можно было перенести в
конфигурацию.

Если бота удаляют из незнакомого чата, discovery не срабатывает: такое
событие не помогает настроить проект.

Токены и полные invite-ссылки в эти логи не пишутся.
