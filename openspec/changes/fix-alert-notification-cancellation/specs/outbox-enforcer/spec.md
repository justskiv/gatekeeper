## ADDED Requirements

### Requirement: Enforcer skips an action whose linked alert is no longer open

Действие, несущее ссылку на операционную тревогу, MUST проверяться перед
исполнением. Проверка MUST выполняться после успешного lease и до вызова
исполнителя: раньше — не у кого спрашивать, позже — сообщение уже ушло.

Если тревога больше не открыта, воркер MUST перевести действие в `cancelled`
вместо исполнения, тем же fencing-переходом, что и остальные терминальные
записи, и MUST залогировать пропуск на уровне info с идентификаторами действия
и тревоги. Такое действие MUST NOT считаться ни выполненным, ни отказавшим:
попытки не списываются, `admin_alert` о мёртвом действии не создаётся.

Ошибка чтения состояния тревоги MUST проваливаться в обычное исполнение.
Сбой чтения MUST NOT глотать уведомление: цена ложной отмены — молча
потерянное сообщение о критической проблеме, цена ложной доставки — сообщение,
устаревшее на секунды.

Действие без ссылки на тревогу MUST исполняться без этой проверки.

Проверка — вторая линия, а не первая: основную работу делает отмена очередей в
момент резолва, а воркер закрывает окно, в котором строка была взята lease'ом
непосредственно перед резолвом. Гарантия остаётся best-effort — тревога,
резолвнувшаяся после проверки, MUST NOT считаться предотвращённой доставкой.

#### Scenario: Уведомление о резолвнутой тревоге не отправляется
- **WHEN** воркер лизит `send_dm`, связанный с тревогой, которая уже резолвнута
- **THEN** Telegram-вызов не выполняется
- **AND** действие переходит в `cancelled`, а не в `done` и не в `dead`
- **AND** пропуск попадает в лог с id действия и id тревоги

#### Scenario: Нечитаемое состояние тревоги не отменяет доставку
- **WHEN** чтение состояния связанной тревоги завершается ошибкой
- **THEN** действие исполняется обычным путём
- **AND** ошибка чтения попадает в лог

#### Scenario: Действие без связи с тревогой не платит за проверку
- **WHEN** воркер лизит действие без `alert_id`
- **THEN** состояние тревог не запрашивается
- **AND** действие исполняется обычным путём
